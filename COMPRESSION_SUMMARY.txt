================================================================================
                         COMPRESSION TECHNIQUE
================================================================================

TWO-STAGE LOSSLESS COMPRESSION:

Stage 1: PNG Encoding (Lossless)
  └─ NumPy array → PNG format
  └─ Removes storage redundancy
  └─ ~40% size reduction

Stage 2: Zlib Compression (Lossless)
  └─ PNG bytes → zlib (level 6)
  └─ Additional ~20% reduction
  └─ Like ZIP/GZIP compression

Total Result:
  └─ Original array → PNG + zlib
  └─ 50-60% size reduction
  └─ ZERO quality loss ✅
  └─ Same pixel-perfect images

WHY LOSSLESS?
  ✅ PNG is lossless (not JPEG)
  ✅ Zlib is lossless (like ZIP)
  ✅ No data thrown away
  ✅ Perfect reconstruction on decompression
  ✅ AI gets same exact images → same accuracy
